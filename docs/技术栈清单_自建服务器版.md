# 项目合同管理系统 —— 技术栈清单（自建服务器版）

> 前提：自购云服务器自行部署，不依赖 Vercel / Supabase 等海外托管服务。全程由 AI 编程工具（如 Claude Code）辅助开发和部署。
> 本文档为**实际落地技术栈**（第一轮开发已按此实现并通过验证）。

## 前端 + 后端

| 项目    | 选型                                                                   |
| ------- | ---------------------------------------------------------------------- |
| 框架    | Next.js 16（React 19 + TypeScript,App Router）                          |
| UI 组件 | shadcn/ui（**Base UI 版本**）+ Tailwind CSS 4 + lucide-react           |
| 表单    | react-hook-form + zod                                                   |
| 状态    | 服务端组件 + 客户端数据组件模式（RSC 容器 / Client 组件）               |
| 说明    | 前后端合一（页面 + API Routes 在同一个项目里），减少前后端对不上的风险 |

## 数据库

| 项目     | 选型                                                            |
| -------- | --------------------------------------------------------------- |
| ORM      | Prisma 7（`@prisma/adapter-pg` driver adapter）                  |
| 主数据库 | PostgreSQL（唯一对接目标，已在开发/验证环境落地）                |
| 部署方式 | 直接安装在自己的云服务器上，不使用云托管数据库服务              |
| 迁移     | `prisma.config.ts` 声明 datasource；`pnpm prisma migrate deploy` |

## 文件存储

| 项目 | 选型                                                             |
| ---- | ---------------------------------------------------------------- |
| 方式 | 服务器本地磁盘存储（发票文件 / 验收单文件，按 `UPLOAD_DIR` + 年份分目录） |
| 白名单 | 图片 / PDF / Word / Excel，单文件不超过 20MB（`saveUpload` 校验） |

## 认证与权限

| 项目     | 选型                                                                |
| -------- | ------------------------------------------------------------------- |
| 认证     | JWT（jose）写入 httpOnly cookie（`compact_token`）                   |
| 权限     | 角色（超级管理员/管理员/财务/普通成员）+ 公司主体过滤 + 成员行级权限 |
| 登录安全 | 密码连续错 5 次锁定 15 分钟；重置密码后强制下次登录修改              |

## 运行环境（本地开发）

| 项目     | 版本要求           |
| -------- | ------------------ |
| Node.js  | ≥ 22（验证于 v26） |
| pnpm     | ≥ 11               |
| PostgreSQL | ≥ 14             |

## 服务器与部署（规划）

| 项目     | 选型                                            |
| -------- | ----------------------------------------------- |
| 云服务器 | 2核4G，40-50GB 系统盘，3-5M 带宽                |
| 操作系统 | Ubuntu 22.04 LTS                                |
| 反向代理 | Nginx（负责域名转发、HTTPS 证书、静态文件加速） |
| 进程守护 | PM2 或 Docker（保证服务重启后自动拉起）         |
| SSL 证书 | Let's Encrypt（免费，自动续期）                 |
| 域名     | .com 或 .cn 域名，需完成国内备案                |

## 技术栈总览表

| 层       | 选型                                                       |
| -------- | ---------------------------------------------------------- |
| 前端     | Next.js 16 + React 19 + TypeScript + shadcn/ui(Base UI) + Tailwind CSS 4 |
| 后端     | Next.js API Routes（与前端同项目）                          |
| ORM/数据库 | Prisma 7 + PostgreSQL（自建于云服务器）                     |
| 文件存储 | 服务器本地磁盘（`UPLOAD_DIR`，按年分目录）                  |
| 认证     | JWT（jose）+ httpOnly cookie                                |
| 部署环境 | Ubuntu 22.04 + Nginx + PM2/Docker + Let's Encrypt           |
